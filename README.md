Landing de un solo libro para Ediciones Urano (propuesta de Equipo GC). Sitio estático: `index.html`, `styles.css` y `assets/`.

- Íconos de redes: Phosphor Icons (licencia MIT).
- Las fotografías, la portada y el logotipo pertenecen a sus respectivos titulares.
